# Homebrew tap for Vulture

[Vulture](https://github.com/alsaadii98/vulture) is a free, open-source cleaner and disk tool for macOS that explains every file before it removes anything.

```bash
brew install --cask alsaadii98/vulture/vulture
```

This also installs the `vulture` command. Vulture updates itself; `brew upgrade --cask --greedy vulture` works too.

The cask in `Casks/vulture.rb` is updated automatically by Vulture's release workflow. Report problems at https://github.com/alsaadii98/vulture/issues.
